# WebDAV 云存档同步（dr3-webdav v1）

内置宿主的存档云同步（`platform/ios/Sources/WebDavSync.m`，移植自 d2r-mobile 生态的
d2r-webdav 真机验证实现）：启动时下拉、**游戏自动保存的当下**自动上传、切后台立即推送。
任何标准 WebDAV 服务器（坚果云、NAS、局域网自建均可）。**默认关闭，零配置零动作。**

## 配置（手机上改，重启 App 生效）

App 开了文件共享：用「文件」App 进入 `DR3 Mobile` 的目录，在 `Documents/` 下新建
`webdav.json`：

```json
{
  "enabled": true,
  "url": "https://dav.jianguoyun.com/dav/",
  "user": "你的账号@example.com",
  "pass": "应用密码（坚果云：网页端 账户信息→安全选项→添加应用密码，不是登录密码）",
  "dir": "dr3-saves",
  "boot_timeout": 5,
  "poll_interval": 2.0,
  "debounce": 3.0
}
```

| 字段 | 含义 | 默认 |
|---|---|---|
| `url` | WebDAV 服务器（http/https） | 必填 |
| `user` / `pass` | 账号（Basic 认证） | 空 |
| `dir` | 云端子目录 | `dr3-saves` |
| `boot_timeout` | 启动下拉硬超时秒数 | 5 |
| `poll_interval` | 轮询扫描间隔秒 | 2.0 |
| `debounce` | 轮询发现变化后的防抖秒 | 3.0 |

云端布局（`dir` 之下）：`manifest.json` + `packs/save.pack`（整个存档一个单元，自定义无压缩 pack 格式，magic `D3W1`）。

## 工作方式（安全边界）

- **只碰已提交存档目录**（`Documents/save`）。宿主的存档是事务式的（`hle_fs.c`）：游戏只写
  工作副本，Commit 时整目录原子换入——已提交目录永远是一份完整快照，本模块扫到的不会有半写状态。
- **启动下拉**：在启动器点「开始」时起线程取云端 manifest，按修改时间比较（新者赢）；
  等待完成或硬超时（默认 5 秒，到点即弃，绝不装一半）之后才放行游戏主线程——
  下拉与游戏挂载存档在时序上**绝无竞争**。被换下的本机整档进备份（留 3 份，
  `Library/Application Support/DR3WebDAV/backup/`）。**这个窗口过后，本次运行绝不再写本地存档。**
- **推送时机 = 游戏自动保存的当下**：宿主存档提交成功的钩子（`g_dm_save_commit_hook`）
  立即唤醒推送——通常自动保存后一秒内打包上传。另有 2 秒轮询兜住不经提交的直写
  （如赛季旁路表 `dm-season-heroes.tsv`），防抖 3 秒；切后台触发一次立即推送；
  没传完的下次启动补推。运行中只读本地、只写云端。
- **防倒退守卫**（比 d2r-webdav v1 多的一道）：每次推送前重取云端 manifest，
  若云端比本机上次同步视图新、也比本机当前档新（另一台设备推过更进的进度），
  本次不推，留给下次启动下拉对齐——杜绝「陈旧补推覆盖云端新档」。
- WebDAV 细节（真机经验）：MKCOL 父先子后、PUT 409/404 补建目录重试、
  503/429（坚果云限速）10/30/90 秒退避；manifest 只记真正传成功的。

## 日志与自检

- 文件：App 的 `Documents/webdav.log`（超 200KB 自动截半），「文件」App 里直接看。
- 控制台：过滤 `dr3-webdav`。
- 自检：`webdav.json` 里加 `"selftest": true` 重启 App，只跑 pack 往返测试并写日志，不同步。

## 第一次真机测试清单（重要）

1. **先备份**：用爱思/签到工具把 App 整个数据目录（或至少 `Documents/save`）拉一份到电脑。
2. 首次装好先确认零伤：不配 `webdav.json` 装一次，进游戏玩几分钟，确认一切正常（无配置零动作）。
3. 配好 `webdav.json` 重启，点「开始」后看 `webdav.log`：应有「启动」「启动窗口关闭（下拉已完成）」。
4. 玩到自动保存 / 退出存档，应出现「推送（存档提交）：save(...)」「推送：save → 云端」；
   WebDAV 端确认 `manifest.json` 和 `packs/save.pack` 出现。
5. 卸载重装（或第二台设备）验证下拉：云端比本地新时应看到「下拉：save ← 云端」，进游戏验证进度完整。

## 已知限制（v1）

- **后写赢**按各设备本地时钟的修改时间，两台设备时钟差太多可能选错赢家
  （被覆盖方有 3 份备份可手工找回）。
- 两台设备**同时**游玩时整档互推（后写覆盖先写）——单人多设备顺序使用无感；
  防倒退守卫保证推送不会覆盖确定更新的云端。
- 整个存档是一个同步单元（D3 存档跨文件一致，不能像 D2R 那样按角色分单元拼装）；
  单元体积上限 64MB（实测存档远小于此）。
- 换新 WebDAV 服务器/目录前先备份；`dir` 名一换等于换了片云。
- 锁屏后文件可能因 iOS 文件保护读不了：后台推送失败不打紧，下次启动补推。
