# D3 移动端虚拟按键 UI 设计（触控模式专用布局）

> 2026-11-04。目标：替代「通用 Switch 手柄模拟」的按键 UI，为 D3 定制一套
> 移动端布局——按钮直接标功能、低频功能收进顶栏、为触控施法留好演进路径。
> 键位语义已由逆向 + 真机实测定标（见 §一）。

## 一、键位语义（逆向 + 实测定标）

从 main NSO 挖出的输入动作注册名：`Move`、`Skill1`、`Skill2`、`Skill3`、`Skill4`、
`Potion`（DrinkHealthPotion）、`TownPortal`；主机版 UI 里 `PotionButton`、
`HotbarButtonData`、`AssignSkillToSlot`（游戏内置技能槽重映射，KeyBindings 面板 ×70）。

结合真机实测（包=+、单=− 已由用户验证）与主机版键位：

| 物理键 | D3 功能（默认绑定） | 移动端呈现 |
|---|---|---|
| 左摇杆 | `Move` 移动 | 左下大摇杆（不变） |
| 右摇杆 | 世界光标移动（`CursorSetToRightStick` 实证） | 触控成熟后由「手指点屏幕」取代 |
| **A（右）** | `Skill1`（鼠标左键位技能）+ 交互/确认 | 技能环中心大键 |
| **B（下）** | 关闭/取消 | 环外小键（面板导航用） |
| **X（左）** | `Skill2` | 环上 |
| **Y（上）** | `Skill3` | 环上 |
| **R（右肩）** | `Skill4`（鼠标右键位技能） | 环上 |
| **L（左肩）** | 第二技能组 / 移动类技能 | 环上（可选，见 §三） |
| **ZL** | `Potion` 药水（`PotionButton`） | 摇杆旁专用键 |
| **ZR** | `TownPortal` 城镇传送 | 顶栏 |
| **+** | 背包/物品面板（实测） | 顶栏「包」 |
| **−** | 系统菜单（实测） | 顶栏「单」 |
| 十字键 | 面板页签/快捷导航 | 收进面板导航（游戏内页签用触摸） |
| L3 / R3 | 少用（强制站立/光标吸附） | 默认隐藏（设置里可开） |

> 待实测确认（装机后一轮验证）：L 是否独立技能、十字键在游戏内的实际用途。
> 映射做成可配置，错了改配置不用改代码。

## 二、布局设计（第三种模式「D3」）

现有 2D（简单）/3D（Pro 手柄）保留，新增 **D3 布局**，触控模式默认选它；
物理手柄接入时整个虚拟层隐藏（现有行为不变）。

```
┌─────────────────────────────────────────────────────────────┐
│ [包][单][城]   （顶栏：背包/菜单/城镇传送，小 pill 半透明）      │
│                                                             │
│            〔游戏画面 / 触控区：点哪走哪（v2）〕                │
│                                                             │
│                                  ┌───┐                      │
│                        ┌───┐     │ 3 │Y                     │
│ ● 血球                 │ 4 │R ┌───┴───┴───┐                  │
│  (移到这里)             └───┘ │  1(攻击)  │ ←中心大键          │
│                 ┌───┐         └───┬───┬───┘                   │
│   ◯ 摇杆       │ 2 │X           ┌───┐  ┌───┐                  │
│  （左下）       └───┘             │ B │  │药 │ZL                │
│                                  └───┘  └───┘                  │
└─────────────────────────────────────────────────────────────┘
```

**分区原则**：
- **左下** = 移动（摇杆）+ 药水（高频救命键，摇杆顺手位置）
- **右下** = 技能环（Skill1 中心大键直径 ~90pt，Skill2/3/4 环绕 135° 扇形，
  键径 ~56pt，环半径 ~85pt——拇指扇形摆动可达）
- **顶栏** = 低频面板键（包/单/城，高 ~28pt，贴 safe-area 顶部，避免误触）
- **中屏** = 完全留给游戏与触控（v2 世界光标后：点地走路/点怪打怪/点物拾取）
- HUD 移位完成后（血球/技能条 → 上角），下半屏无遮挡，操作区与信息区彻底分离

**视觉**：
- 技能键底座沿用现有哑光圆盘美术（DmTouchControlArt 缓存体系），中心键加一圈
  高亮描边标识「主攻击」
- 标签用语义字（「攻」「2」「3」「4」「药」「包」「单」「城」）而非 A/B/X/Y——
  玩家不需要知道 Switch 键位；后续把技能图标（游戏 .tex 抽帧）贴进键面
- 冷却显示：技能键外圈描边转圈（v1.5，先不做）

## 三、交互规则

1. **技能键 = 点按**：按下即合成对应手柄键（现有 `dm_input_set` 通路，零宿主改动），
   在当前世界光标处施法（D3 主机版语义：A = 光标处放左键技能）
2. **B 键**：只在面板打开时显示（`dm_uiscreen` 类似的面板信号；v1 常显）
3. **顶栏键**：点按即开对应面板；顶栏在战斗中自动降透明度（不遮挡）
4. **多指并发**：现有 touch 仲裁（锁定键优先 → 距离分配）沿用；游戏区触摸（C_GAME）
   与技能环互不抢占
5. **物理手柄接入**：虚拟层整体隐藏（现有行为）；拔出回到 D3 布局

## 四、演进路径（与触控合流）

| 阶段 | 内容 | 依赖 |
|---|---|---|
| v1（本轮） | D3 布局重摆 + 语义标签 + 顶栏四键 | 无（纯前端） |
| v1.5 | HUD 移位落地后默认启用 D3 布局；冷却圈；键面技能图标（.tex 抽帧） | HUD 移位校准 |
| v2 | 触控施法：点世界 = 移光标（右摇杆合成 v1 / 光标直写 v2），技能环中心键 = 在光标处施法；拾取 = 点物品 + A | 触控 v2 校准 |
| v3 | 技能拖拽施法（按住技能键拖到目标点松手 = 定向施法）；键位自定义面板 | v2 稳定 |
