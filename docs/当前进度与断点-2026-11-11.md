## 七、新教训（本轮）

1. **LDR imm12×4=字节偏移**：扫 `ldr w?,[x?,#0x12c]` 要用 imm12=0x4B，直接写 0x12c 会扫到 +0x4b0（120 个真站点差点错过）。
2. **GitHub trees API 递归大查询连跑触发 403 次级限流**（分钟级窗口）；`api()` 重试逻辑当时只认 5xx/429——403 也要长退避（d3e48ae）。同模式短间隔重跑 CI 会叠加限流，失败后先等再跑。
3. **修编译错先确认改的是哪一行**（25a6e45 改错行的教训：同名常量两处使用，报错行号才是准星）。
4. shell_build xcodebuild 失败不吐日志=CI 抓瞎——失败打印尾部 80 行（41e3d8d）已永久解决。
